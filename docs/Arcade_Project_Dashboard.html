Wiring Guide

Lap Pad — Simplified Power Chain

No boost converter. The Brook Gen 5W accepts 3.7V directly.

Step-by-Step Wiring

Step 1 — Qi Receiver to TP4056

Solder Qi receiver V+ to TP4056 IN+, Qi receiver GND to TP4056 IN-. The Qi module outputs regulated 5V — exactly what the TP4056 expects as input power.

Step 2 — TP4056 to Battery

Connect TP4056 BAT+ to LiPo positive, BAT- to LiPo negative. The built-in DW01 protection IC handles over-discharge, over-charge, and short circuit protection.

Step 3 — Battery to Brook Gen 5W

The Brook board uses a JST PH 2.0mm battery connector. Re-terminate the LiPo leads with a JST PH 2.0mm plug, or use a pigtail adapter. Verify polarity — reversed polarity will destroy the board.

Step 4 — Joystick

Connect UP/DOWN/LEFT/RIGHT switches to Brook Gen 5W directional terminals. Joystick common wire to GND on the Brook board.

Step 5 — 6 Action Buttons

Connect each button signal wire to Brook P1–P6 terminals. All button grounds daisy-chain to Brook GND.

Step 6 — OLED Display

Connect SDA/SCL to Brook I2C header. VCC to 3.3V or 5V (check module spec). GND to GND. Confirm I2C address matches the Brook display driver.

RetroPie Configuration

gpio-keys Overlay — /boot/config.txt

Each button maps to a unique key code so the system can distinguish all inputs.

# Corrected key codes for RetroPie # Each button has a unique code for proper identification dtoverlay=gpio-keys,gpio=17,keycode=2,label="Player 1 Start" dtoverlay=gpio-keys,gpio=27,keycode=3,label="Player 2 Start" dtoverlay=gpio-keys,gpio=22,keycode=4,label="Player 3 Start" dtoverlay=gpio-keys,gpio=23,keycode=5,label="Player 4 Start" dtoverlay=gpio-keys,gpio=24,keycode=6,label="Select" dtoverlay=gpio-keys,gpio=25,keycode=7,label="Hotkey"
gpio-keys creates a virtual keyboard, not a gamepad This works but needs RetroArch keyboard-to-gamepad mapping. For native joystick device support, use the mk_arcade_joystick_rpi driver below.

Alternative: mk_arcade_joystick_rpi Driver

Presents GPIO buttons as proper joystick devices (/dev/input/jsX) — natively recognized by EmulationStation.

# Installation cd /home/pi git clone https://github.com/recalbox/mk_arcade_joystick_rpi.git cd mk_arcade_joystick_rpi sudo mkdir /usr/src/mk_arcade_joystick_rpi-0.1.5 sudo cp -a * /usr/src/mk_arcade_joystick_rpi-0.1.5/ sudo dkms build -m mk_arcade_joystick_rpi -v 0.1.5 sudo dkms install -m mk_arcade_joystick_rpi -v 0.1.5 # Load the driver sudo modprobe mk_arcade_joystick_rpi map=1 # Auto-load on boot — add to /etc/modules: mk_arcade_joystick_rpi

Brook Gen 5W Bluetooth Pairing

1. Enter Pairing Mode

Hold the pairing button on the Brook Gen 5W for 3 seconds until the LED flashes rapidly.

2. RetroPie Bluetooth Menu

Navigate to: RetroPie Setup > Configuration / Tools > Bluetooth > Register and Connect to Bluetooth Device

3. Select and Pair

Select the Brook controller from the discovered devices list. Once paired, the LED will go solid.

4. Configure Input

In EmulationStation, press any button to trigger input configuration. Map joystick and all 6 buttons.

Multi-Player RetroArch Config

Edit /opt/retropie/configs/all/retroarch.cfg

# Map each Brook controller to a player slot input_player1_joypad_index = "0" input_player2_joypad_index = "1" input_player3_joypad_index = "2" input_player4_joypad_index = "3"
